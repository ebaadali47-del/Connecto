# Connecto

Connecto is a web-based social networking platform developed as a Java web application. The platform allows users to create accounts, manage their profiles, connect with other users based on shared interests, and interact through a database-driven web interface.

The project was built to gain practical experience with Java web development, MVC-based application structure, server-side request handling, JSP, Servlets, and relational database integration.

## Features

* User registration and login
* User profile management
* Interest-based user connections
* User search and discovery
* Dynamic JSP-based pages
* Servlet-based request and response handling
* MySQL database integration
* Session-based user management
* Responsive web interface
* Form validation and database-driven functionality

## Technologies Used

* **Java** — Application logic and backend development
* **JSP** — Dynamic web pages
* **Java Servlets** — Request handling and backend processing
* **MySQL** — Database and data management
* **HTML5** — Page structure
* **CSS3** — Styling and layout
* **JavaScript** — Client-side interactions

## Database

The project uses MySQL for storing application data such as user accounts, profiles, interests, and connections.

A database export is included in:

database/socialconnector.sql


The SQL file can be imported into MySQL to recreate the database structure and required data.

## Running the Project

1. Clone or download the repository.
2. Create a MySQL database.
3. Import `database/connecto.sql`.
4. Configure the database connection in the project.
5. Deploy the project using a Java web server such as Apache Tomcat.
6. Start the server and open the application in a browser.
